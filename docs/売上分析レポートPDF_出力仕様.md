# 月次売上分析レポート PDF 出力仕様

「`build_sales_report.py`が生成した月次売上分析Excel」を**読み取り専用**で読み込み、
固定体裁のPDFレポートを別ファイルとして生成するための仕様。実装は
`tools/build_sales_pdf.py`。**このスクリプトにも特定の月名・年月・目標金額・
店舗名・商品名・施策名を一切ハードコードしていない。** すべて `--excel` で渡された
Excelファイルの中身から読み取る。

## 1. 実行方法

```bash
python3 tools/build_sales_pdf.py --excel <build_sales_report.py が出力したxlsx>
```

- `--excel`（必須）: `build_sales_report.py`が出力したExcel（サマリー/日次推移/
  店舗別/チャネル別/カテゴリ別/顧客区分別/クリーニング済明細の7シート構成）。
  **このファイルは読み取り専用で開き、一切上書き・変換しない。**
- `--out`（任意）: 出力PDFのパス。省略時は `--excel` と同じフォルダに、
  Excelの「日次推移」シートの日付から読み取った年月を使って
  `YYYY年M月_売上分析レポート.pdf` として保存する（年月を手入力しない）。

## 2. ページ構成（固定・6ページ）

明細（クリーニング済明細）は含めない。常にこの順序で6ページ。

1. サマリー
2. 日次推移
3. 店舗別
4. チャネル別
5. カテゴリ別
6. 顧客区分別

## 3. ページ仕様

- 用紙: **A4横**、余白 **15mm**（上下左右）
- 全ページ共通ヘッダー（余白帯の上部）:
  - 左: `{年}年{月}月 売上分析レポート`
  - 右: `対象期間：{日次推移シートの最初の日付} - {最後の日付}`（`yyyy/m/d`表記）
- 全ページ共通フッター（余白帯の下部）:
  - 中央: `{ページ番号} / {総ページ数}`
  - 右: `出典：{渡されたExcelファイルの実際のファイル名}`
- ページタイトル（各ページ本文の先頭、18pt太字、濃紺）: 「1. サマリー」「2. 日次推移」
  「3. 店舗別」「4. チャネル別」「5. カテゴリ別」「6. 顧客区分別」
- グラフはページ上部、対応する表はその下に配置する
  - 日次推移 → **折れ線グラフ**（サマリーページにも縮小版を掲載）
  - 店舗別・チャネル別・カテゴリ別・顧客区分別 → **棒グラフ**（サマリーページには店舗別のみ縮小掲載）
  - 色はExcel既定のテーマアクセント1と同じ `#4472C4` を使用する
- 日次推移の表は1か月分（最大31行）が1段に収まらないため、
  月前半／月後半の2列に分けて配置する（合計行は右側の列の末尾に置く）

## 4. 書式

- フォント: 全ページ **Noto Sans CJK JP**（日本語対応・Regular/Boldとも実在するフォント
  ファイルを明示的に埋め込み、実行環境のフォント差し替えに左右されない）
  - 本文: 10pt
  - 見出し（グラフタイトルなど）: 14pt
  - ページタイトル: 18pt
- 数値の表示形式（Excel側の書式と同じ見え方にする。**値そのものは再計算しない**）:
  - 金額: `¥#,##0`
  - 率: 小数第1位＋`%`
  - 日付: `yyyy/m/d`
- 表:
  - ヘッダー行: 濃紺 `#1F3864`・白文字・太字
  - データ行: 白 / 薄いグレー `#F2F2F2` の交互
  - 罫線は横罫のみ（縦の罫線は引かない）

## 5. 数値の取り扱い

- PDFに書き出す数値・文字列はすべてExcelの該当セルの値を**そのまま転記**する。
  PDF生成スクリプト側での再計算・合計のやり直し・端数処理は行わない
  （表示用に ¥ やカンマ、% を付ける整形のみ行う）。
- Excel側で 0 だった行（実績のない店舗・チャネル・カテゴリ・顧客区分、
  売上のなかった日）もそのまま行として出力し、省略しない。
- Excel側の「新規項目」列の値、サマリーの「記載なし」といった注記文字列も
  そのまま引き継いで表示する。

## 6. 品質確認

- 生成後、PDFの各ページを画像化して目視確認し、フォントの文字化け・字形の崩れ・
  グラフや表のはみ出し／重なりがないことを確認する
  （`pdftoppm -png -r 300 report.pdf page` などで高解像度画像化して確認するとよい）。
- Excel側の値とPDF表示値を突き合わせ、転記ミスがないことを確認する。

## 7. 依存関係

- Python: `openpyxl`, `matplotlib`
- フォント: `fonts-noto-cjk`（`Noto Sans CJK JP` の Regular/Bold を含む）が
  システムにインストールされていること
  （未導入の場合は `apt-get install fonts-noto-cjk` でインストールする）
